# Changelog

## v0.1.0

- Initial Linux TUI for multiple Task Spooler queues.
- Auto-discovery of conventional active tsp Unix sockets.
- Manual queue registration for arbitrary `TS_SOCKET` paths.
- Queue/task overview, task info, output tailing, submit, kill, remove, clear, urgent and slots controls.
- CLI commands for queue listing, JSON status, diagnostics, queue registration and task submission.
- Pure Go standard-library implementation; static Linux builds.
